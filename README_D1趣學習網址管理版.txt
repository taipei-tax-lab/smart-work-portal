智慧工作入口｜D1 趣學習網址管理版

這版不用 R2、不需付費。

管理設定 → 趣學習｜內容管理 可直接：
- 選分類：互動遊戲 / 同仁作品 / 影音學習
- 選內容類型：一般連結 / 遊戲 / 圖片 / 影片 / PDF
- 填標題、說明、提供單位
- 填封面圖片網址
- 填內容網址
- 顯示 / 隱藏
- 排序
- 新增 / 刪除

支援：
- GitHub Pages 圖片網址
- Google Drive 圖片分享網址（系統會嘗試轉成可顯示格式）
- YouTube 影片網址（趣學習頁可直接嵌入播放）
- 一般 mp4 影片網址
- PDF 網址
- Tax Melody 等互動遊戲網址

資料仍透過原本的 D1 /api/portal-settings 共用同步，
不用建立新的 D1，也不用修改 Worker。
