【返回鈕與趣學習後台管理版】

管理密碼：11

新增管理功能：

一、返回智慧工作入口按鈕
- 修改文字
- 選擇左上 / 右上 / 左下 / 右下
- 調整按鈕大小
- X / Y 位置微調
- 套用於主要子頁

二、趣學習管理
- 新增新遊戲 / 新案
- 修改圖示、名稱、說明、連結
- 顯示 / 隱藏
- 刪除
- 上移 / 下移排序

顯示規則：
- 只有 1 個啟用的趣學習項目：首頁點「趣學習」直接進入。
- 2 個以上：先進趣學習選擇頁。

注意：
目前管理資料仍存於瀏覽器 localStorage。
若未來要讓「你在一台電腦新增遊戲，所有同仁電腦立即同步看到」，
需要再接共用資料庫後台。
