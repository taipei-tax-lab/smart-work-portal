## 視覺一致性

- 保留原角色的臉型、斑紋、服裝、TRS 胸章、書本與配色。
- 背景維持透明。
- 角色尺寸與畫布基準保持一致，避免播放時跳位。
- 不以整張圖旋轉代替真正的手臂姿勢變化。
